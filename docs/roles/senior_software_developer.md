# Senior Software Developer

## Purpose
Deliver high‑quality code, mentor peers, and drive technical excellence across software projects.

## Core Responsibilities
- Design, implement, and review complex features in collaboration with product owners.
- Write clean, testable, and documented code following style guidelines.
- Conduct code reviews and enforce coding standards.
- Mentor Junior developers and lead knowledge‑sharing sessions.
- Identify and resolve technical debt, performance bottlenecks, and security gaps.
- Participate in architectural discussions and propose improvements.
- Maintain CI/CD pipelines and ensure reliable releases.

## Common Tools
- IDEs: VS Code, IntelliJ, PyCharm.
- Version control: Git, GitHub/GitLab.
- Build tools: Maven, Gradle, Webpack, Vite, Docker.
- Testing frameworks: Jest, PyTest, JUnit.
- CI/CD: GitHub Actions, GitLab CI, Jenkins.
- Issue trackers: Jira, Trello.

## Key Skills
- Proficiency in at least one programming language used by the organization (e.g., JavaScript/TypeScript, Python, Go).
- Strong grasp of fundamentals: data structures, algorithms, concurrency, networking.
- Experience with test‑driven or behavior‑driven development.
- Knowledge of DevOps practices: containers, orchestration.
- Ability to design and implement APIs, both RESTful and GraphQL.

## Typical Tasks for AI Reference
- *Add a new feature:* create feature branch, implement code, write tests.
- *Fix a bug:* analyze stack trace, reproduce locally, patch, and commit.
- *Update documentation:* modify README or API docs.
- *Run CI locally:* `docker compose up --build`.
