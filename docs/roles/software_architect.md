# Software Architect

## Purpose
Define the high‑level structure of the company's software systems, ensuring scalability, maintainability, and alignment with business goals.

## Core Responsibilities
- Design system architecture: domain models, component interfaces, data flow, and deployment topology.
- Evaluate and recommend technology stacks, frameworks, and design patterns.
- Lead technical decision making and trade‑off analysis.
- Mentor developers on design practices and coding standards.
- Review technical designs, code, and architecture documentation.
- Ensure compliance with security, performance, and regulatory requirements.

## Common Tools
- UML / PlantUML, Mermaid for diagrams.
- Architecture modeling: ArchiMate or Enterprise Architect.
- Dependency analysis: SonarQube, CodeQL.
- Project management: Jira, Azure DevOps.
- Documentation: Markdown, MkDocs.

## Key Skills
- Strong foundation in software design principles (SOLID, GRASP).
- Experience with distributed systems, microservices, cloud platforms.
- Knowledge of database design, caching, and scalability patterns.
- Ability to translate business requirements into technical specifications.
- Excellent communication for collaborating with stakeholders.
