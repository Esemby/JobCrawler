# Junior Software Developer

## Purpose
Build reliable software under guidance, learn best practices, and contribute to team velocity.

## Core Responsibilities
- Implement user stories or bug fixes under senior review.
- Write unit and integration tests.
- Participate in code reviews; apply feedback.
- Keep documentation up to date with changes.
- Learn and adopt the company’s technology stack and standards.
- Collaborate with cross‑functional team members.

## Common Tools
- IDEs: VS Code, IntelliJ, PyCharm.
- Version control: Git.
- Build/run: npm/yarn, Python virtualenv, Docker.
- Testing: Jest, PyTest, Mocha.
- Issue tracking: Jira.

## Key Skills
- Basic proficiency in the organization’s primary language (e.g., Python, JavaScript).
- Understanding of Git workflow (feature branch, pull request).
- Good coding style, readability, and debugging.
- Willingness to ask questions and seek mentorship.

## Typical Tasks for AI Reference
- *Create a new component:* `npx create-react-app my-comp`.
- *Run a test suite:* `npm test`.
- *Open a pull request:* push branch, navigate to GitHub and click "New pull request".
- *Add documentation:* edit Markdown files.
